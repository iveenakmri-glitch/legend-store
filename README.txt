LEGEND STORE — RGB GOLD EDITION

This is a static website starter package.

PUBLISH WITH NETLIFY (PHONE OR COMPUTER)
1. Extract this ZIP file so you can see index.html.
2. Open https://app.netlify.com/drop in your browser.
3. Sign in or create a Netlify account.
4. Upload the extracted folder containing index.html (or drag the extracted files).
5. Wait for deployment, then open the public URL Netlify gives you.

LIMITATIONS
- The site is static. Cart and owner demo settings are stored only in the current browser.
- Owner tools are NOT secure authentication and do not sync between devices.
- Orders are not automatically sent to the owner; the customer copies the summary and contacts the owner separately.
- UPI is displayed for manual payment only. No automatic processing or payment verification.
- Verify resale authorization and provider terms before selling any digital service.
- Never request or store customers' passwords, cookies, tokens, UPI PINs, or OTPs.
- A real shop needs a backend/database, authenticated admin access, and a verified contact channel.
